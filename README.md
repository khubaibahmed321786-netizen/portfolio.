# Khubaib Ahmed | Software Engineering Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript (no build step).
Made for the Parallel and Distributed Computing additional activity, Department of Software Engineering, University of Sindh.

**Live site:** _add your Vercel or Netlify URL here_

## Sections
Home, About, Career Objective, Education, Technical Skills, Projects (with a case study), Experience, Certifications, Achievements, GitHub, Resume and Contact.

## How to run
1. Clone the repository.
2. Open `index.html` in a browser. No install or build is needed.

All content lives in the `C` (contact) and `D` (content) objects at the top of the `<script>` in `index.html`.

## Folder structure
- `index.html`: the whole site (HTML, CSS, JS)
- `resume/`: put `Khubaib_Ahmed_CV.pdf` here
- `certificates/`: certificate images (`cert1.jpg` to `cert4.jpg`)
- `projects/`: project screenshots (`project1.jpg`)
- `favicon.svg`

## Deploy
Import this repository from Git in Vercel or Netlify. It is a static site, so no build command is needed and the publish directory is the repository root.
